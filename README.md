# コーディング試験 README

## 概要
本コーディング試験では、UIデザインの構築スキル、プログラミングスキルやコードの可読性、設計力を評価します。

### 実装の条件
- TypeScript、React / Vueなどのライブラリを使用
- SPAとして動作すること
- テストコード（Jest, Testing Library）を最低1つ含めること
- `buildings.json`を参照し、デザインにある項目を出力すること

## 期限
期限は原則14日以内。\
早期に完成した場合は、ご提出ください。延長が必要な場合はSlackでご連絡ください。

## 課題
デザインファイルを参考に、データを参照・整形し、要件を満たすWebアプリケーションを作成してください。

### 要件
1. 検索画面で建物を検索し、検索結果を地図にマーカーでプロットする
2. 検索結果に対するキャップレート推移と稼働率推移の分析グラフの平均値を表示する

以上の2つの要件は必ず満たしてください。

### 不合格について
- 環境構築に失敗する
- インタラクションが動作せず、操作に著しい支障をきたす
- クラッシュする

以上の場合は、要件未達として不合格になります。
提出前に必ず動作確認をしてください。

### デザインファイル
Figmaをローカルファイルでお渡し致します。
要件を満たした上でのデザインの改変は可能です。\
その場合は、任意でデザインファイルもご共有ください。評価点の対象になります。

### データ
`src/mocks/buildings.json`にあるデータの説明です。\
実際のプロダクトではBackend側から呼び出すデータです。
```
  "data": {
    "jReitBuildings": [
      {
        "id": "bb4acc0899fc681d4354f23bda42d26d1136d539dea9c096ceff170168e33d37",
        "acquisition": {
          "acquisitionPrice": 15100000000, // 取得時取引価格
          "acquisitionDate": "2003-09-10", // 初回取得日
          "initialCapRate": "4.80",　// 取得時CR(キャップレート)
        },
        "buildingSpec": {
          "address": "東京都渋谷区宇田川町21番6号", // 住所
          "completedMonth": 10, // 竣工月
          "completedYear": 1999, // 竣工年
          "grossFloorArea": "2019.34", // 延床面積
          "latitude": "35.6598986111111", // 緯度
          "longitude": "139.700305277778", // 経度
          "name": "QFRONT(キューフロント)", // 建物名
          "netLeasableAreaTotal": "1255.35" // 貸付可能面積
        },
        "yieldEvaluation": {
          "appraisedPrice": 39200000000, // 最新鑑定評価額
          "capRate": "2.40" // 最新CR(キャップレート)
        },
        "assetType": { // アセットの種類
          "isOffice": false, // オフィス
          "isRetail": true, // 商業施設
          "isHotel": false, // ホテル
          "isParking": false, // 駐車場
          "isIndustrial": false, // 工場
          "isLogistic": false, // 物流施設
          "isResidential": false, // 住宅
          "isHealthCare": false, // 医療施設
          "isOther": false // その他
        },
        "transfer": {
          "transferDate": null // 譲渡日
        },
        "capRateHistories": [ // キャップレートの履歴
          {
            "id": "6ae27e590fddcfad894dd76f67d60d5e1979b02b96b9f18522008e5aef016091",
            "jReitBuildingId": "bb4acc0899fc681d4354f23bda42d26d1136d539dea9c096ceff170168e33d37", // jReitBuildings.idと同様の値
            "capRate": "4.80", // キャップレート
            "closingDate": "2003-09-10" // 決算期の締め日（初回は初回取得日）
          },
        ],
        "financials": [ // 決算データ
          {
            "leasing": { // 賃貸状況に関するデータ
              "occupancyRate": "100.00" // 稼働率
            }
          }
        ]
      }
    ]
  }
```

#### 稼働率推移グラフについての補足
- `financials`配列には日付が含まれていないため、グラフの日付は`capRateHistories`の`closingDate`を参照してください
- `financials`と`capRateHistories`は配列の長さが異なる場合があります。対応するindexが存在しないデータは除外して構いません

## 環境
リポジトリにはNext.jsのデータを配置していますが、Remix, Nuxtなど任意のフレームワークを使用することが可能です。
Lintなど、ご自由に設定・インストールしてください。
環境再現に必要手順があれば、こちらのドキュメントに追記してください。

### デフォルトの推奨環境
- Node.js: v20以上
- パッケージマネージャ: npm
- Visual Studio Code

### セットアップ手順
```sh
# リポジトリをクローン
$ git clone https://github.com/estie-inc/{repo_name}.git
$ cd {repo_name}

# 依存関係をインストール
$ npm install # または yarn install

# 開発サーバー起動
$ npm run dev # または yarn dev
```

## 提出方法
1. `main` ブランチから、機能・要件ごとに`feature/{任意の名前}` ブランチを作成してください。
2. 課題を実装し、コミットメッセージを適切に記述してください。
3. プルリクエストを作成し、mainにmergeしてください。
4. 試験担当者に完了の旨をご連絡ください。

## 評価基準
- 要件を満たすこと
- 状態管理やデータの取り扱いの基礎的な理解があること
- コンポーネント設計が適切か
- TypeScriptを活用し、型定義が適切か
- コードの可読性（一貫したスタイルや命名規則）
- UIの実装精度（デザインの再現性）
- エラーハンドリングが適切か
- テストが含まれているか
